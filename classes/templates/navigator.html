Campus Navigator

The four regular campuses plotted from their geographic coordinates, with the straight-line distance between each pair calculated by the Java backend (Haversine formula).

Positions use approximate town-centre coordinates (not exact campus gates), so relative placement is accurate but exact campus points should be confirmed. Distances are straight lines, not road distances.
